# YOLOv11-Pose 坐姿检测器

用 **YOLOv11-Pose** 提取人体 17 个关键点，实时判断当前坐姿属于哪一类，并在画面上标出躯干线与判定结果。

| 判定 | 含义 | 触发条件（默认阈值） |
|---|---|---|
| ✅ Normal | 坐姿正常 | 三个指标都在阈值内 |
| 🌀 Hunchback | 弯腰驼背 | 躯干与竖直方向夹角 > 25° |
| ⬇️ Head down | 低头趴桌 | 鼻子相对肩中点下移 > 30 px |
| 📐 Skew | 身体侧歪 | 双肩高度差 > 35 px |

界面基于 Gradio：支持**摄像头实时检测**与**上传图片检测**，返回标注后的画面 + 中文判定文本。

## 快速开始

```bash
# 1) 建议用虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

# 2) 安装依赖
pip install -r requirements.txt

# 3) 启动
python app.py
# 浏览器打开 http://127.0.0.1:7860
```

首次运行会自动下载 `yolo11n-pose.pt`（约 6 MB），之后离线可用。
需要公网临时链接时加 `--share`；指定监听地址用 `--host 0.0.0.0 --port 7860`。

## 原理

```text
图像 ──▶ YOLOv11n-pose ──▶ 17 个 COCO 关键点(x, y, conf)
                                   │
                     取 鼻(0) / 双肩(5,6) / 双髋(11,12)
                                   │
              ┌────────────────────┼────────────────────┐
              ▼                    ▼                    ▼
        躯干角 vs 竖直        鼻相对肩中点下移        双肩高度差
        > 25° → 驼背          > 30px → 低头          > 35px → 侧歪
```

**判定优先级**：弯腰驼背 → 低头趴桌 → 身体侧歪 → 正常。
一个人可能同时满足多个条件，按上述顺序取第一个，避免同一帧出现互相矛盾的标签。

关键点置信度低于 `0.4` 的人体直接跳过（遮挡/背影时关键点不可信，强行判定会误报）。

## 检测规则（可调）

所有阈值集中在 `app.py` 顶部，改完立即生效：

| 常量 | 默认值 | 作用 |
|---|---|---|
| `PERSON_CONF` | 0.5 | 人体检测置信度阈值 |
| `KEYPOINT_CONF` | 0.4 | 关键点可用性阈值（低于则跳过该人） |
| `TORSO_ANGLE_MAX` | 25° | 躯干与竖直方向夹角上限 |
| `HEAD_DROP_MAX` | 30 px | 鼻尖相对肩中点的最大下移距离 |
| `SHOULDER_DIFF_MAX` | 35 px | 双肩最大高度差 |

> ⚠️ `HEAD_DROP_MAX` / `SHOULDER_DIFF_MAX` 是**像素阈值**，与画面分辨率、人距镜头的远近有关。
> 换摄像头或换分辨率后需要重新标定；更稳的做法是按人体框高度归一化（见"改进方向"）。

## 项目结构

```text
yolo/
├── app.py            # 检测逻辑 + Gradio 界面（全部代码）
├── requirements.txt  # ultralytics / opencv-python / numpy / gradio
├── .gitignore
└── README.md
```

`app.py` 里三块职责清晰分开：

- `calculate_torso_angle()`：纯数学，无副作用；
- `classify_posture()`：输入关键点，输出判定（与画图解耦，方便单独测试/复用）；
- `posture_detect()`：Gradio 回调，负责画图与汇总文本。

## 相比最初脚本修正的几个问题

整理成仓库时顺手修了几个实际会影响使用的问题：

1. **颜色不对**：OpenCV 是 BGR，Gradio 期望 RGB，原脚本直接返回导致红蓝互换 —— 现在返回前统一转 RGB；
2. **中文乱码**：`cv2.putText` 不支持中文，原脚本把中文画在图上会变成问号 —— 现在画面上只画英文标签，中文放文本框；
3. **输入为空会崩**：没上传图片时先返回友好提示，而不是抛异常；
4. **判定与绘制耦合**：拆出 `classify_posture()`，便于加单元测试或换个界面复用；
5. **日志噪音**：推理时关掉 ultralytics 的逐帧输出。

## 已知局限

- **视角依赖**：侧身、背影或关键点被遮挡时，肩/髋中点不可靠，判定会失效（已用置信度过滤兜底）；
- **像素阈值**：换分辨率/距离后阈值需重标；
- **单帧判定**：没有时序平滑，抖动帧可能造成标签闪烁；
- **通用模型**：用的是通用 COCO 姿态模型，不是为坐姿场景专门训练的。

---

## 改进方向

- 阈值按人体框高度归一化（`dist / bbox_height`），跨分辨率稳定；
- 多帧滑动窗口投票或 EMA 平滑，消除标签闪烁；
- 增加"歪头""距离过近"等类别；
- 记录久坐时长并做提醒（需要时序状态机）；
- 导出 ONNX，做端侧部署（树莓派 / 手机 / 眼镜等）。
